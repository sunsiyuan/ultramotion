参考 ultramotion.ai 的「液态玻璃」风格做一条视频：https://ultramotion.ai/styles/liquid-glass/
这个风格是开源的 Agent Skill。能装 skill 的话，先运行 npx skills add sunsiyuan/ultramotion，用里面的 liquid-glass 模板（scene.html 画画面，score.py 出配乐）来做；装不了，就照下面的描述从头写一个。

【成片】
- 竖屏 1080×1920，30 fps，16 秒，带配乐和音效的 mp4，放在当前目录。
- 整条视频是一个网页画出来的：每一帧都是时间 t 的纯函数，不在帧之间留状态。用无头浏览器（Playwright / Puppeteer / Chrome --headless）逐帧 seek(t) 截图，再用 ffmpeg 编码（libx264，yuv420p），最后把配乐合进去（-shortest）。
- 要能随便跳到任意一帧渲染；放慢某一段就把 t 的步长调小，每一帧依然清楚。

【玻璃长什么样】
- 苹果 Liquid Glass 那种玻璃：透明、带厚度，边缘一圈有折射，把背后的东西放大、弯折，边缘带一点很淡的 RGB 色散（大约 ±5%，多了黑字周围会出彩边）。
- 玻璃形状用有向距离场（SDF）画：圆角矩形和圆。几块玻璃靠近时用平滑并集（smooth union）融成一滴，拉开时先拉出细颈再断开——不要两块硬碰硬地叠在一起。融合半径大约 40–150 px，长出新块的那一下调大，块站稳以后调小。
- 背后是柔和流动的渐变：薰衣草紫 #8a78e6、淡丁香白 #e7e3f3、青蓝 #8cc9d8，墨色 #1b1b22，强调蓝 #3b7bf6。渐变一直在慢慢流，但不能抢戏。
- 分两层：A 层在玻璃后面，会被折射（大标题放这层）；B 层贴在玻璃上面，不折射（图标、标签、界面细节放这层）。
- 字体用干净的无衬线（SF Pro / Inter / 苹方一类），大标题 200–250 px，字重 600。

【怎么动——这就是这个风格】
- 弹出带回弹：形状出现时用弹簧曲线，冲过头约 12% 再落回，像果冻。
- 沿运动方向拉长：移动中的玻璃顺着方向拉长、横向变窄，停下时再变回圆。
- 融合与分裂：分成几颗按钮、从邻居身上长出一块、全部收回成一滴，都只是移动形状，融合交给平滑并集。
- 透镜扫字：一块圆形玻璃从字上扫过，字在边缘被放大、弯折。
- 字一个一个从下往上浮出来，从模糊到清楚；退场时往侧面一抹带模糊。
- 节奏 120 BPM，重要的动作落在拍点上。

【分镜：五段，左上角一个小 HUD 写段名和 01/05】
01 MORPH（0–3 秒）：画面中央弹出一滴圆玻璃 → 横向拉成一条胶囊 → 胶囊分成三颗圆按钮，按钮上依次浮出「播放」「红心」（红色 #ff375f）「分享」三个图标 → 三颗按钮收回、融成一块方形玻璃。
02 REFRACT（3–6.8 秒）：后面浮出两行大字「Liquid」「Glass」，一块圆形透镜按 Z 字形扫过：左上 → 右上 → 右下 → 左下，经过的地方字被放大、弯折；最后透镜缩小一点，停到左上角，为下一段让位。
03 BLEND（6.8–9.9 秒）：那块玻璃变成控制中心的方块，从它身上一块接一块长出五块，排成 2×3 的格子，每块上有图标、名字和状态：Wi-Fi / Home、Focus / Off、Glass Hearts / Nova Bloom（音乐）、Light / 72%、Sound / 40%、Torch / Off。随后点亮 Wi-Fi（整块染成蓝色、字变白）和手电筒（染成黄色），各配一声点击。然后六块全部滑回中心，融成一滴。
04 NAVIGATE（9.9–12.8 秒）：那一滴横向摊开成底部的标签栏，上面一个大字「Fluid.」浮出。标签栏四个标签：Home、Search、Activity、Profile；选中块像水一样在标签之间滑动（Home → Search → Profile → Activity），滑动时被拉长、到位后回圆，选中的图标变蓝。
05 MERGE（12.8–16 秒）：标签栏收回成一块圆形透镜，从左到右扫过大标题「液态玻璃」，下面一行小字「LIQUID GLASS · STYLE 01」字距拉开淡入；最后透镜缩成一个小圆点，停在标题右下角，像一个句号。

【声音】
- 配乐用代码合成（numpy / scipy 就够，不用外部素材）：柔和的 pad 铺底 + 玻璃感的钟琴琶音 + 轻鼓，120 BPM。
- 每一次弹出、融合都要有一声「水滴」：0.2、1.0、1.75、2.55、7.25、7.47、7.69、7.91、8.13、9.3、9.9、12.8、15.0 秒左右。
- 额外音效：3.0 / 3.55 / 5.2 秒呼的一声扫过，6.4 秒一道上扫，8.4 / 8.75 秒两下点击，10.7 / 11.4 / 12.1 秒标签切换的短促提示音，13.65 秒呼的一声，14.2 秒结尾一声钟鸣。
- 声音和画面的时间点从同一份数据里来，别各写一遍。

【交付前自己检查】
- 从成片里抽 8–10 帧拼成一张图看一遍。
- 透镜下的黑字周围有暗环或橙边：色散或边缘折射太强，收一点。
- 一块从另一块身上长出来时中间有一条细缝：融合半径不够大。
- 标题比设定的小：字太长被缩了，拆成两行或缩短，不要再降字号。
