参考 ultramotion.ai 的「综艺花字」风格，给我的视频加花字：https://ultramotion.ai/styles/variety-captions/
这个风格是开源的 Agent Skill。能装 skill 的话，先运行 npx skills add sunsiyuan/ultramotion，用里面的 variety-captions 模板（scene.html 画花字，vc.py 找脸、排位置、出片，sfx.py 出音效）来做；装不了，就照下面的描述从头写一个。

素材：【把你的视频路径填在这里，比如 ./探店.mp4】
下面的例子是一条 18.6 秒的探店口播（竖屏，一个人试吃网红火锅）。换成你的素材时，花字的文字全部从你视频里说的话来，节奏照这个例子。

【成片】
- 和原片同样大小（竖屏 1080×1920，30 fps），保留原片的声音，在上面叠花字、字幕、推镜和音效，导出 mp4 放在当前目录。
- 花字画在一个透明画布的网页上，每一帧都是时间 t 的纯函数；用无头浏览器逐帧截图，再和原片逐帧叠起来，最后用 ffmpeg 编码。

【第一步：听写和找脸】
- 用 Whisper（或任何能给出每个字时间的语音识别）把视频转成带时间戳的文字。
- 逐帧找到脸（或宠物的头）在哪儿（macOS 用 Apple Vision，其他系统用 mediapipe）。每个花字按它在屏幕上那段时间里脸的位置来摆，绝对不能盖住脸，也不能和角标、字幕、正在显示的另一个花字叠在一起。

【花字的种类】
- 大字 pop：圆润、粗、带描边的大字，一个字一个字弹出来，旁边冒小闪光，字号 150–220 px，可以歪一点（±4–6°）；上面可以带一行小字。默认摆在脸下面（胸口、桌面、食物上）。
- 角标 tag：左上角一个胶囊形标签，写节目名，全程不走。
- 爆炸框 burst：爆炸形状 + 速度线 + 一下白闪，用在整条视频反应最大的那一刻，摆在头顶上方。
- 警告框 warn：黄黑斜纹的框，会抖、会闪，提前一两秒预告「要来了」。
- 名牌 name：带一条头衔的名字卡，有个小箭头指向人，摆在脸旁边。
- 问号 ask：几个飘着的问号，摆在脸旁边。
- 汗滴 sweat：两滴汗往下滑。
- 竖排字 vertical：一列字一个一个出来，冷场时用。
- 印章 stamp：红色圆形印章砸下来，用在最后的结论。
- 颜色只用：黄、粉、青、绿、红、白。
- 字体：大字、角标、名牌用圆润的粗体（中文站酷快乐体，英文 Luckiest Guy）；爆炸框和警告框中文用思源黑体 Heavy；字幕用粗的无衬线。

【分镜（照着这个例子）】
- 全程：左上角粉色角标「探店 EP.07」；每一句话下面都有字幕。
- 0–2.65 秒「今天带大家试吃一家网红火锅」：1.2 秒弹出黄色大字「网红火锅」，上面一行小字「试吃一家」，歪 -4°，配一声闪光音。
- 3.86–6.0 秒「排队排了整整两个小时」：4.2 秒脸边滑下两滴汗（不配音）；5.05 秒红色爆炸框「两个小时！」，同时画面往脸上推近到 1.2 倍。
- 6.0 秒「终于吃上了」：粉色大字「终于！」歪 5°，配一声往上滑的音。
- 7.26 秒「先来一片牛肉」：7.4 秒脸旁边出名牌，头衔「试吃员」，名字「小陈」（不配音）。
- 10.25 秒：头顶出警告框「前方高能」，带警报声。
- 12.1 秒「嗯……好辣好辣好辣」：红色爆炸框「辣！！」，配着火的音效，画面推近到 1.22 倍。这是全片最大的一下，它前面那一秒要安静。
- 13.6 秒「到底值不值？」：13.75 秒脸旁边飘问号（不配音）。
- 15.0 秒：没人说话，竖排字「空气突然安静」一个字一个字出来（不配音，冷场本身就是笑点）。
- 16.04 秒「值！真的绝绝子」：绿色巨字「值！」（280 px，歪 -6°），配「哒哒」的成功音，画面推近到 1.12 倍；17.3 秒红色印章「绝绝子」砸下来。

【节奏】
- 每一个反应都在带出它的那个字上出花字：惊讶、结论用大字，受罪、抱怨用汗滴或大字，提问用问号，冷场用竖排字，介绍人用名牌，最后的结论用印章。
- 同一时间只有一个大花字，每个停 1–2.5 秒；大字只写几个字，写笑点，不写整句。

【音效】
- 音效用代码合成（numpy / scipy），叠在原片自己的声音上。大约一半的花字配音，冷场和标签不配音。
- 按当时发生的事选：出现、俏皮 → boing / pop；最大的一下 → duang / 镲；预告 → 警报 / 心跳；好东西、可爱 → 闪光 / 叮；成功、结论 → 哒哒；失望 → 哇哇 / 下滑；兴奋 → 上滑；辣、上头 → 着火；冷场 → 蟋蟀；紧张 → 咽口水 / 滴；印章 → 咚。
- 两个音效之间至少隔 0.8 秒；同一种音重复出现时换个音高。

【交付前自己检查】
- 从成片里抽 8–10 帧拼成一张图看一遍。
- 花字压在脸上：换个位置。
- 字母或汉字挤在一起：这个词太长了，缩短，或拆一部分到上面那行小字。
- 屏幕上同时有两个大花字：错开时间，或者删掉一个。
- 字幕被缩成很细的一行：这句太长，拆成两条字幕。
