Claude Motion, and an open-source way to do the same in Claude Code

On October 8, 2026, Anthropic released Claude Motion: you ask for an animation, Claude builds it, and you download it as an MP4. It is in beta on Team and Enterprise plans. Here is what it does, who can use it, and what to use if you are on another plan or work in Claude Code or Codex.

What Claude Motion does

You ask Claude to animate something. Anthropic's examples are a quarterly report turned into a 30-second explainer for an all-hands, a chart in a board deck, and a product walkthrough for customer onboarding. Claude builds the animation, you adjust it in the editor or by asking ("slow down the second scene"), and you export an MP4. Type /motion in the message box to start.

It does not use a video generation model. Claude writes code that animates your text, charts, shapes and images, so you can change any word, number or timing and the rest stays as it was. There is no generated footage and no AI-generated people. Finished animations open in Adobe, Descript, HeyGen, Higgsfield, invideo, Luma AI and Runway, with Canva and Captions coming.

Who can use it

Team and Enterprise plans, in beta. It is on by default for Team; on Enterprise, an owner turns it on under Organization settings → Artifacts. It counts toward your normal usage limits. It is not available on Free, Pro or Max.

The same idea, in your agent

ultramotion works the same way: the animation is code, every frame is computed from the time, and the result is an MP4. The difference is where it runs. It is a set of open-source Agent Skills for Claude Code, ChatGPT Codex and other agents that load skills. Each style is a self-contained scene.html plus a script that generates the music. Your agent adapts the scene to your content, renders it frame by frame in a headless browser and adds the soundtrack.

Which one to use

If your company is on a Team or Enterprise plan and you want to explain a report or a chart, with an editor to fine-tune it, use Claude Motion: it is built in and made for exactly that. If you are on another plan, already work in Claude Code or Codex, want a particular look for social video, or want the source, use ultramotion.
