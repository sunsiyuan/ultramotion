How it works


The glass is an element with a backdrop-filter that points at an SVG filter. The filter blurs what is behind the element, then pushes each pixel sideways using a displacement map: a small image, made for this exact size and shape, that leaves the middle alone and pushes harder the closer a pixel is to the rim. That is what makes the edge bend the background instead of just frosting it. A few inset shadows add the highlight on the rim.


Refraction through backdrop-filter works in Chrome, Edge, Brave, Arc and other Chromium browsers. Safari and Firefox don't apply SVG filters to the backdrop yet, so the code gives them a frosted version of the same glass instead. The map is drawn for one size: if you change the element's size, make a new one here.
