Remotion for beginners, or skip the setup

Remotion lets you make videos with React: you write components, drive them with the current frame, and render with Node. It is powerful, and it is a real coding project. If you are looking at Remotion because you want videos made from code, but you don't write React, there is a shorter path: let your AI agent do the coding from a ready-made template.

What ultramotion is

A set of open-source motion templates packaged as Agent Skills, for Claude Code, ChatGPT Codex and other agents that load skills. Each one is a self-contained scene.html, where the frame is a pure function of time, plus a score.py that generates the music. You ask for a video; the agent adapts the scene to your content, captures it frame by frame with a headless browser, encodes it with ffmpeg and adds the soundtrack.

When Remotion is the better choice

If you are a React developer, need to render thousands of personalised videos, or want video generation inside your own product, use Remotion. ultramotion is for when you want the video, not a video codebase.

Try it

npx skills add sunsiyuan/ultramotion

Then ask your agent, for example: "Make a 15-second countdown for our launch in the Kinetic Type style." Browse the styles to see what each one looks like.
