# Effects

One shot each: a sign switching on, a glitch cut, a number rolling. Each page is a short, complete piece built on one engine — copy it (and the engine files and media its tags load), keep how it moves, its timing and its sound, and put the user's content in; the comment at the top of the page says what to change. Read the engine's GUIDE.md before changing how it moves.
