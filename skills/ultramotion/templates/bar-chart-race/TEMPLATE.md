# Bar Chart Race · 【数据动画】排名赛跑

How a ranking of countries, cities or brands changed over decades. (GDP、城市、品牌排名几十年怎么变)

Engine: `lib/data-story/` — read its GUIDE.md.

## Start from

- `gdp-race.html` — Chinese
- `super-bowl-race.html` — English

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- What is ranked (in the example: the ten largest economies)
- From when to when (in the example: 1990–2025)
- The one to follow (in the example: India)
- Data source (in the example: World Bank)

Use real data and compute every number on screen from the data file.

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
