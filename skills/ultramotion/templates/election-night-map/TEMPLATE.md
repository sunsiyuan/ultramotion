# 3D Election Night Map · 【3D 地图】开票之夜

An election night, results coming in place by place. (选举开票、各地结果一个个出来)

Engine: `lib/event-replay/` — read its GUIDE.md.

## Start from

- `election-2024.html`

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- The election (in the example: the 2024 US presidential election)
- The night, in order (in the example: states as the Associated Press called them, with their real call times; look them up)
- The ending (in the example: the call that passes 270)

Use the real results and name the source.

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
