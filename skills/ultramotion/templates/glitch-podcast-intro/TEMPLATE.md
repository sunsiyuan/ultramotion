# Glitch Podcast Intro · 【故障风】播客开场

A tech podcast, a cold open. (科技播客、节目冷开场)

Engine: `lib/glitch/` — read its GUIDE.md.

## Start from

- `dead-pixels-112.html` — English
- `houtai-jincheng.html` — Chinese

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- Show and episode (in the example: DEAD PIXELS · Episode 112)
- The episode title (in the example: The Day the Cloud Went Down)
- The moment it goes wrong (in the example: the host's voice cuts out mid-sentence — "and then every system was—")

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
