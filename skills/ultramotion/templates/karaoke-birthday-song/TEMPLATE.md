# Birthday Song Card · 【毛笔字】生日祝福歌

A birthday card for the family chat, each line written as it is sung, with their name in the song. (发到家庭群的生日贺卡，唱到哪一句写出哪一句，歌里唱出名字)

Engine: `lib/karaoke/` — read its GUIDE.md.

## Start from

- `grandpa-joe-90.html` — English
- `waipo-85.html` — Chinese

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- For whom (in the example: Grandma)
- Turning (in the example: 85)
- The line with their name (in the example: Happy birthday, dear Grandma)

Format: Vertical 1080×1920, 30 fps.

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
