# Milk Pour Coffee Loop · 【奶倒进咖啡】新品循环屏

A new drink on a café menu screen or in an ad. (咖啡店、茶饮店的新品和菜单屏)

Engine: `lib/mesh-gradient/` — read its GUIDE.md.

## Start from

- `iced-matcha-en.html` — English
- `oat-latte-zh.html` — Chinese

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- Shop name (in the example: Kettle & Leaf, Seattle)
- The drink and the price (in the example: Iced Matcha Latte · $6)
- What is poured into what (in the example: cold milk poured over iced matcha)

Format: Landscape 1920×1080, 30 fps.

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
