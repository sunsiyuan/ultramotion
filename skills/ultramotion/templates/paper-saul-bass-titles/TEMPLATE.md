# Saul Bass Style Title Sequence · 【剪纸动画】话剧预告

A trailer or opening titles for a play, a film, an exhibition. (话剧、电影、展览的预告片头)

Engine: `lib/paper/` — read its GUIDE.md.

## Start from

- `chicago-noir.html` — English
- `duimen.html` — Chinese

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- Title (in the example: CHICAGO NOIR)
- One image (in the example: a figure in a hat, cut into pieces)
- Dates and venue (in the example: Film week · Feb 5–11, 2027 · Music Box Theatre)

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
