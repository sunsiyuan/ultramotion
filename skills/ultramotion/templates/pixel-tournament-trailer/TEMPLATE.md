# Pixel Art Tournament Trailer · 【像素风】比赛预告

A sports day, a league, a game night: the events one by one. (运动会、联赛、游戏之夜：几个项目一个个登场)

Engine: `lib/pixel/` — read its GUIDE.md.

## Start from

- `ct-olympics.html`

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- The event (in the example: CT Olympics)
- Where (in the example: NYC vs Dubai)
- The events (in the example: perps trading, boxing, memecoin trading, 100M dash, 5k)
- The last line (in the example: WHO SAYS YES?)

Everything to change is in CONTENT and COLORS at the top of the html; each event is its own small scene, so write one for each of yours; people are posed by their joints with Pixel.figure().

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
