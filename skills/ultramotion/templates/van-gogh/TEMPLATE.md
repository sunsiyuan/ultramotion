# Van Gogh Painting Animation · 【油画笔触】梵高

Art explainers, a painting talk, an exhibition. (艺术科普、名画讲解、展览宣传)

Engine: `lib/painterly/` — read its GUIDE.md.

## Start from

- `cafe-terrace.html` — English
- `starry-night-original.html` — English
- `starry-night.html` — English
- `sunflowers.html` — English
- `wheatfield-crows.html` — English

Copy the starting file that matches the user's language (and the media it loads) into the project and keep its look, pacing, camera, type and music. Change only what the user's content changes:

- Which Van Gogh painting (in the example: The Starry Night)
- What should move in it (in the example: the turning sky, the stars, the cypress in the wind)

Paint from the original (a public-domain image of it) and keep the strokes running the way the painter laid them.

If the words are longer or shorter, change the size and the line breaks, not the structure. Write the content for the user's place and audience; don't translate the example's.
