Kinetic Type

Heavy condensed type slamming in on the beat, with full-frame colour-block cuts — for gig promos, quotes and countdowns.

Use it

Install the skills, then ask your agent for a video in this style. For example:

npx skills add sunsiyuan/ultramotion
